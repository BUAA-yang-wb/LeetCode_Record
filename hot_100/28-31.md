# LeetCode 热题链表题解汇总

## 2. 两数相加

### 思路

两个链表中的数字是逆序存储的，因此可以从头节点开始逐位相加。

使用变量 `carry` 记录进位。每一位计算：

```text
当前位结果 = (l1 当前值 + l2 当前值 + carry) % 10
新的进位 = (l1 当前值 + l2 当前值 + carry) // 10
```

只要 `l1`、`l2` 或 `carry` 还有值，就继续生成新节点。

### 代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def addTwoNumbers(
        self,
        l1: Optional[ListNode],
        l2: Optional[ListNode]
    ) -> Optional[ListNode]:
        dummy = ListNode(0)
        cur = dummy
        carry = 0

        while l1 or l2 or carry:
            x = l1.val if l1 else 0
            y = l2.val if l2 else 0

            total = x + y + carry
            carry = total // 10

            cur.next = ListNode(total % 10)
            cur = cur.next

            if l1:
                l1 = l1.next
            if l2:
                l2 = l2.next

        return dummy.next
```

### 简要解析

以 `2 -> 4 -> 3` 和 `5 -> 6 -> 4` 为例：

```text
2 + 5 = 7
4 + 6 = 10，当前位是 0，进位 1
3 + 4 + 1 = 8
```

所以结果是：

```text
7 -> 0 -> 8
```

## 19. 删除链表的倒数第 N 个结点

### 思路

使用快慢指针。

让 `fast` 先走 `n` 步，然后 `fast` 和 `slow` 一起向后移动。当 `fast` 到达最后一个节点时，`slow.next` 就是要删除的节点。

为了方便处理删除头节点的情况，使用虚拟头节点 `dummy`。

### 代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def removeNthFromEnd(
        self,
        head: Optional[ListNode],
        n: int
    ) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        slow = dummy
        fast = dummy

        for _ in range(n):
            fast = fast.next

        while fast.next:
            fast = fast.next
            slow = slow.next

        slow.next = slow.next.next

        return dummy.next
```

### 简要解析

以 `1 -> 2 -> 3 -> 4 -> 5`，`n = 2` 为例。

`fast` 先走 2 步，然后 `fast` 和 `slow` 同时移动。

当 `fast` 到达节点 `5` 时，`slow` 位于节点 `3`，此时 `slow.next` 是节点 `4`，删除它即可。

结果是：

```text
1 -> 2 -> 3 -> 5
```

## 24. 两两交换链表中的节点

### 思路

每次处理两个相邻节点，将它们的位置交换。

使用虚拟头节点 `dummy`，并用 `prev` 表示当前要交换的一组节点前面的节点。

原结构：

```text
prev -> first -> second -> next
```

交换后：

```text
prev -> second -> first -> next
```

### 代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def swapPairs(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        prev = dummy

        while prev.next and prev.next.next:
            first = prev.next
            second = prev.next.next
            nxt = second.next

            prev.next = second
            second.next = first
            first.next = nxt

            prev = first

        return dummy.next
```

### 简要解析

以 `1 -> 2 -> 3 -> 4` 为例。

第一轮交换 `1` 和 `2`：

```text
2 -> 1 -> 3 -> 4
```

第二轮交换 `3` 和 `4`：

```text
2 -> 1 -> 4 -> 3
```

## 25. K 个一组翻转链表

### 思路

每次先检查后面是否还有 `k` 个节点。

如果不足 `k` 个，剩余节点保持原顺序；如果够 `k` 个，就反转这一组。

使用 `group_prev` 表示当前组前面的节点，先找到当前组的第 `k` 个节点 `kth`，再记录下一组的开头 `group_next`。

然后反转区间：

```text
[group_prev.next, group_next)
```

反转完成后，再把当前组和前后链表连接起来。

### 代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        group_prev = dummy

        while True:
            kth = group_prev
            for _ in range(k):
                kth = kth.next
                if not kth:
                    return dummy.next

            group_next = kth.next

            prev = group_next
            cur = group_prev.next

            while cur != group_next:
                nxt = cur.next
                cur.next = prev
                prev = cur
                cur = nxt

            old_group_head = group_prev.next
            group_prev.next = kth
            group_prev = old_group_head
```

### 简要解析

以 `1 -> 2 -> 3 -> 4 -> 5`，`k = 2` 为例。

第一组反转：

```text
2 -> 1 -> 3 -> 4 -> 5
```

第二组反转：

```text
2 -> 1 -> 4 -> 3 -> 5
```

最后节点 `5` 不足一组，保持原样。

这题可以记住一个模板：

```text
先找 kth，再保存 group_next，然后反转 [group_prev.next, group_next)
```
