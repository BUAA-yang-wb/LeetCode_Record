# LeetCode 热题 100：矩阵相关题解汇总

## 73. 矩阵置零

### 思路

不能在遍历时遇到 `0` 就立刻把对应行列清零，否则新产生的 `0` 会影响后续判断。

可以用矩阵的第一行和第一列作为标记数组：

- `matrix[i][0] == 0` 表示第 `i` 行需要清零
- `matrix[0][j] == 0` 表示第 `j` 列需要清零

由于第一行和第一列本身也可能需要清零，所以额外用两个变量记录它们最初是否包含 `0`。

### 代码

```python
class Solution:
    def setZeroes(self, matrix: list[list[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        m, n = len(matrix), len(matrix[0])

        first_row_zero = False
        first_col_zero = False

        for j in range(n):
            if matrix[0][j] == 0:
                first_row_zero = True
                break

        for i in range(m):
            if matrix[i][0] == 0:
                first_col_zero = True
                break

        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0
                    matrix[0][j] = 0

        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0

        if first_row_zero:
            for j in range(n):
                matrix[0][j] = 0

        if first_col_zero:
            for i in range(m):
                matrix[i][0] = 0
```

### 简要分析

这题的关键是先标记，再统一清零。

如果使用额外数组记录哪些行列需要清零，思路会更直观，但不是最优的原地做法。利用第一行和第一列做标记，可以避免额外开辟行列数组。

需要特别注意第一行和第一列，因为它们既承担原始数据的角色，又承担标记数组的角色，所以必须提前单独记录它们是否需要清零。

## 54. 螺旋矩阵

### 思路

维护四个边界：

```text
top     上边界
bottom  下边界
left    左边界
right   右边界
```

每一轮按照以下顺序遍历：

```text
从左到右
从上到下
从右到左
从下到上
```

每走完一条边，就把对应边界向内收缩一格。

### 代码

```python
class Solution:
    def spiralOrder(self, matrix: list[list[int]]) -> list[int]:
        if not matrix or not matrix[0]:
            return []

        res = []
        m, n = len(matrix), len(matrix[0])

        top, bottom = 0, m - 1
        left, right = 0, n - 1

        while top <= bottom and left <= right:
            for j in range(left, right + 1):
                res.append(matrix[top][j])
            top += 1

            for i in range(top, bottom + 1):
                res.append(matrix[i][right])
            right -= 1

            if top <= bottom:
                for j in range(right, left - 1, -1):
                    res.append(matrix[bottom][j])
                bottom -= 1

            if left <= right:
                for i in range(bottom, top - 1, -1):
                    res.append(matrix[i][left])
                left += 1

        return res
```

### 简要分析

这题重点是边界控制。

一轮遍历结束后，外层一圈已经被加入结果数组，接下来只需要处理更内层的矩阵。

第三步和第四步之前需要判断：

```python
if top <= bottom:
if left <= right:
```

否则在单行或单列矩阵中，可能会重复加入元素。

## 48. 旋转图像

### 思路

顺时针旋转 90° 可以拆成两步：

```text
先上下翻转
再沿主对角线翻转
```

例如：

```text
1 2 3        7 8 9        7 4 1
4 5 6   ->   4 5 6   ->   8 5 2
7 8 9        1 2 3        9 6 3
```

### 代码

```python
class Solution:
    def rotate(self, matrix: list[list[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        n = len(matrix)

        for i in range(n // 2):
            matrix[i], matrix[n - 1 - i] = matrix[n - 1 - i], matrix[i]

        for i in range(n):
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
```

### 简要分析

顺时针旋转 90° 后，原来的位置变化为：

```text
matrix[i][j] -> matrix[j][n - 1 - i]
```

如果直接按照这个位置关系移动元素，需要小心被覆盖的问题。使用翻转法会更简单，也更容易写对。

这题可以记住一句话：

```text
顺时针 90° = 上下翻转 + 主对角线翻转
```

## 240. 搜索二维矩阵 II

### 思路

从右上角开始搜索。

设当前元素为 `x`：

- 如果 `x == target`，返回 `True`
- 如果 `x > target`，说明当前列下面的元素都更大，可以排除当前列，向左走
- 如果 `x < target`，说明当前行左边的元素都更小，可以排除当前行，向下走

### 代码

```python
class Solution:
    def searchMatrix(self, matrix: list[list[int]], target: int) -> bool:
        if not matrix or not matrix[0]:
            return False

        m, n = len(matrix), len(matrix[0])
        i, j = 0, n - 1

        while i < m and j >= 0:
            if matrix[i][j] == target:
                return True
            elif matrix[i][j] > target:
                j -= 1
            else:
                i += 1

        return False
```

### 简要分析

右上角这个位置很特殊：

```text
左边的数都更小
下面的数都更大
```

所以每比较一次，都可以排除一整行或者一整列。

这题也可以从左下角开始搜索，逻辑类似：

```text
当前值大于 target，向上走
当前值小于 target，向右走
```
