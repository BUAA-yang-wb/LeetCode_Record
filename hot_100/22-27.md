# LeetCode Hot 100 链表题解汇总

## 160. 相交链表

### 代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        pA, pB = headA, headB

        while pA != pB:
            pA = pA.next if pA else headB
            pB = pB.next if pB else headA

        return pA
```

### 简要分析

使用两个指针 `pA` 和 `pB`，分别从两个链表头节点出发。

当 `pA` 走到链表 A 的末尾后，转到链表 B 的头节点；当 `pB` 走到链表 B 的末尾后，转到链表 A 的头节点。

这样两个指针最终走过的总长度相同。如果两个链表相交，它们会在相交节点相遇；如果不相交，它们会同时变成 `None`。

注意，这里判断相交不是看节点值是否相等，而是看两个指针是否指向同一个节点对象。

## 206. 反转链表

### 代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        prev = None
        cur = head

        while cur:
            nxt = cur.next
            cur.next = prev
            prev = cur
            cur = nxt

        return prev
```

### 简要分析

使用 `prev` 和 `cur` 两个指针。

`prev` 表示已经反转好的链表头，`cur` 表示当前正在处理的节点。

每次先保存 `cur.next`，然后把 `cur.next` 指向 `prev`，完成当前节点的反转。之后 `prev` 和 `cur` 分别向后移动。

当 `cur` 走到 `None` 时，`prev` 就是反转后的新头节点。

## 234. 回文链表

### 代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        slow = fast = head

        # 1. 找到链表中点
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        # 2. 反转后半部分链表
        prev = None
        cur = slow

        while cur:
            nxt = cur.next
            cur.next = prev
            prev = cur
            cur = nxt

        # 3. 比较前半部分和反转后的后半部分
        left = head
        right = prev

        while right:
            if left.val != right.val:
                return False
            left = left.next
            right = right.next

        return True
```

### 简要分析

先用快慢指针找到链表中点。

然后从中点开始反转后半部分链表。反转完成后，用 `left` 从原链表头开始，`right` 从反转后的后半部分头节点开始，逐个比较节点值。

如果所有对应节点值都相等，说明链表是回文链表；否则不是。

对于奇数长度链表，中间节点会被包含在后半部分里，但不会影响判断结果。

## 141. 环形链表

### 代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        slow = fast = head

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

            if slow == fast:
                return True

        return False
```

### 简要分析

使用快慢指针。

`slow` 每次走一步，`fast` 每次走两步。

如果链表中有环，`fast` 会在环中追上 `slow`，两者最终会相遇。

如果链表中没有环，`fast` 会先走到 `None`，说明不存在环。

## 142. 环形链表 II

### 代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = fast = head

        # 1. 先判断是否有环
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

            if slow == fast:
                # 2. 一个指针从 head 出发
                p = head

                # 3. 另一个指针从相遇点出发
                while p != slow:
                    p = p.next
                    slow = slow.next

                return p

        return None
```

### 简要分析

先用快慢指针判断链表是否有环。

如果 `slow` 和 `fast` 相遇，说明链表存在环。此时让一个指针 `p` 从 `head` 出发，另一个指针 `slow` 从相遇点出发。

两个指针每次都走一步，它们第一次相遇的位置就是环的入口节点。

如果快慢指针没有相遇，说明链表没有环，返回 `None`。

## 21. 合并两个有序链表

### 代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def mergeTwoLists(
        self,
        list1: Optional[ListNode],
        list2: Optional[ListNode]
    ) -> Optional[ListNode]:
        dummy = ListNode()
        cur = dummy

        while list1 and list2:
            if list1.val <= list2.val:
                cur.next = list1
                list1 = list1.next
            else:
                cur.next = list2
                list2 = list2.next

            cur = cur.next

        cur.next = list1 if list1 else list2

        return dummy.next
```

### 简要分析

使用虚拟头节点 `dummy`，可以避免单独处理新链表头节点。

`cur` 指向新链表的尾部。每次比较 `list1` 和 `list2` 当前节点的值，把较小的节点接到 `cur.next` 后面，然后对应链表指针向后移动。

当其中一个链表为空时，直接把另一个链表剩余部分接到新链表末尾。

最后返回 `dummy.next`，也就是合并后链表的真正头节点。
